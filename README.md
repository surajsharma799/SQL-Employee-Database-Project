# SQL Retail Sales Data Analysis

## Project Overview

This project focuses on **Retail Sales Data Analysis using MySQL**.

The objective of this project is to use SQL to retrieve, filter, analyze, and summarize retail sales data while practicing important SQL concepts used in data analysis.

## Tools Used

* MySQL
* MySQL Workbench
* Microsoft Excel

## Dataset

The dataset contains retail sales transaction information with the following columns:

* Ship Mode
* Segment
* Country
* City
* State
* Postal Code
* Region
* Category
* Sub-Category
* Sales
* Quantity
* Discount
* Profit
